# Plugin `Tabs` or `Splits` rename

@CLAUDE.md

## Contexto

Seria interessante permitir o rename das `Tabs` ou `Splits` para sabermos de forma fácil os contextos que estamos trabalhando. Talvez até uma subtitle para nos **splits** já que uma **tab** pode ter `N` **splits**.

Acha que conseguimos fazer? Se sim, vamos trabalhar com SDD, atualize o documento de especificação de design de software (SDD) na subpasta `plans/sdd/SPEC.md`, seguindo a descrita da arquitetura, componentes, fluxos de dados, e quaisquer dependências necessárias para implementar esta feature no plugin. Atualize também o arquvio HANDOFF.md usado para marcar a progressão do projeto, para servir como um registro de progresso e memória entre seções de trabalho. O HANDOFF.md deve ser atualizado regularmente com notas sobre o progresso, desafios enfrentados, decisões de ‘design’, e quaisquer mudanças no escopo do projeto.
