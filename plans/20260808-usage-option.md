# Claude code usage option

## Contexto

De vez enquanto eu gosto de consultar o consumo do claude code e pra isso preciso enviar o comando `/usage`. Seria possivel no header do plugin criarmos uma opção, após o botão de resume para que ao clicarmos possamos ver em um popup o resumo de uso. 

Acha que conseguimos fazer? Se sim, vamos trabalhar com SDD, atualize o documento de especificação de design de software (SDD) na subpasta `plans/sdd/SPEC.md`, seguindo a descrita da arquitetura, componentes, fluxos de dados, e quaisquer dependências necessárias para implementar esta feature no plugin. Atualize também o arquvio HANDOFF.md usado para marcar a progressão do projeto, para que sirva como um registro de progresso e memória entre seções de trabalho. O HANDOFF.md deve ser atualizado regularmente com notas sobre o progresso, desafios enfrentados, decisões de design, e quaisquer mudanças no escopo do projeto.
